## Featured Projects

### [HeartTrialTwin](https://github.com/akwasianing/HeartTrialTwin)

An experimental research prototype for classifying heart-failure clinical-trial discontinuation. It combines PostgreSQL data extraction, temporal validation, structured features and eligibility-text TF-IDF, a frozen logistic-regression model, integrity checks, transparent contributions, and a Streamlit human-review workflow.

### [Clinical Decision Support RAG for Type 2 Diabetes](https://github.com/akwasianing/clinical-decision-support-rag-diabetes)

A notebook-based RAG system that retrieves from selected ADA guideline sections and generates source-grounded answers. The project demonstrates ChromaDB vector search, Sentence Transformers, cross-encoder reranking, Qwen models, LangChain text splitting, and quantitative retrieval and citation evaluation.

### [PubMedQA LoRA Biomedical Classifier](https://github.com/akwasianing/pubmedqa-lora-biomedical-classifier)

A three-class biomedical question-answering classifier built by adapting PubMedBERT with LoRA. The repository includes the trained adapter, evaluation results, example inputs, and a Streamlit interface for classifying question-abstract pairs as yes, no, or maybe.

### [30-Day Hospital Readmission Tracking Tool](https://github.com/akwasianing/redcap-hospital-readmission-tracker)

A privacy-safe healthcare analytics application built around synthetic longitudinal records and a REDCap-style data dictionary. It combines data-collection design, quality dashboards, an educational logistic-regression risk model, and a Streamlit interface while clearly separating demonstration from clinical use.

### [Human-AI Co-Designed Job Search](https://github.com/akwasianing/CS5588-Challenge1-Human-AI-Job-Search)

An explainable job-matching application that combines BM25 and SBERT retrieval with coverage-aware scoring, eligibility checks, evidence displays, and human review. The repository includes reproducible data snapshots, tests, validated outputs, screenshots, and a live Streamlit application.
